# ThriveMint

A React Native wellness app built with Expo.

## Stack

- Expo SDK 52
- React Navigation (native stack + bottom tabs)
- Supabase
- Stripe React Native

## Getting Started

```bash
npm install
npx expo start
```

## Folder Structure

```
src/
  ├── screens/
  ├── components/
  ├── navigation/
  ├── hooks/
  ├── services/
  ├── context/
  └── utils/
```
